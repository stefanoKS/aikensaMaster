# 4. カメラ①②の校正 / 5. ホモグラフィの算出

## 校正の種類

| 種類 | 目的 | 出力ファイル |
|------|------|--------------|
| 内部校正（ChArUco） | レンズ歪み・焦点距離 | `Calibration_camera_0.yaml` / `Calibration_camera_1.yaml` |
| 内部校正（縮小版） | プレビュー用 | `Calibration_camera_scaled_0.yaml` / `..._1.yaml` |
| ホモグラフィ | カメラ画像 → テンプレート平面 | `homography_param_cam1.yaml` / `cam2.yaml` |
| ホモグラフィ（縮小版） | プレビュー用 | `homography_param_cam1_scaled.yaml` / `cam2_scaled.yaml` |
| 平面化変換 | 台の傾き補正 | `planarizeTransform_wide.yaml` ほか |

**ファイル名は変更しないでください。** 既存の処理がこれらの名前を直接参照しています。

## 内部校正の手順

1. メイン画面 → **カメラ校正1**（カメラ①）または **カメラ校正2**（カメラ②）。
   設備設定の「校正・位置調整」から「カメラ①を再校正」でも同じ画面へ移動します。
2. ChArUco ボードをカメラに映します。
3. 「単フレーム検出」で検出状態を確認します。
   - ボードが検出されない場合は照明・ピント・ボードの大きさを確認してください。
4. 複数姿勢（目安: ボードの角度・位置を変えて 10 枚以上）で撮影します。
   検出に成功したフレームのみが校正データに追加されます。
5. 「校正実行」を押します。
   - 計算に失敗した場合は**既存の校正ファイルは上書きされません**。
     「No calibration matrix calculated; keeping the previous file.」とログに表示されます。
6. 成功すると `Calibration_camera_0.yaml` / `Calibration_camera_scaled_0.yaml` が更新されます。

## ホモグラフィの算出

1. メイン画面 → **カメラマージ**（結合画面）。
2. テンプレート（`aikensa/core/tools/homography_template/homography_template_border.png`）と
   カメラ映像の両方でボードが検出できることを確認します。
3. 「カメラ①ホモグラフィ計算」「カメラ②ホモグラフィ計算」を押します。
   - 共通の検出点が 4 点未満の場合は計算されず、**既存ファイルは保持されます**。
4. 結合画像プレビューで位置ずれが無いことを確認します。

## ホモグラフィの妥当性チェック

保存前に以下が検証されます。

- 3x3 の数値行列であること
- NaN / 無限大が含まれないこと
- 退化していないこと（行列式が 0 でない）
- (3,3) 成分が 0 でないこと

不正な場合は保存されず、以前の正常なファイルが残ります。

## `null`（未校正）の扱い

校正ファイルが `null` の状態では以下が保証されます。

- `cv2.undistort` / `cv2.remap` / `cv2.warpPerspective` は**呼ばれません**
- 「ホモグラフィが未計算です。校正を実行してください。」と表示されます
- アプリはクラッシュしません
- 生産検査は開始されません

## 状態表示

「設備設定」→「校正・位置調整」画面の表で、カメラごとに以下が表示されます。

| 表示 | 意味 | 対応 |
|------|------|------|
| 未設定 | ファイルはあるが `null` | 校正を実行 |
| 未作成 | ファイルが無い | 校正を実行（自動生成されます） |
| 不正 | 内容が壊れている | 再校正 |
| 不適合 | カメラ設定が校正時と違う | 再校正 |
| 準備完了 | 正常 | 対応不要 |

## 注意

- 校正中はカメラを他の画面（検査・プレビュー）が同時に使用することはできません。
  アプリは「カメラ◯は校正で使用中です」と表示します。
- 校正データを変更した後は、必ず基準サンプルで OK/NG 判定を再確認してください。
