# 6. 全体微調整 / 7. 品番別（ウィジェット別）調整

## 全体微調整（全体の位置合わせ）

「校正」と「微調整」は**別物**です。

- **校正（初期校正）** … レンズ・カメラの物理的な特性を求める。やり直すと全品番に影響。
- **全体微調整** … カメラ②がカメラ①に対して数ピクセルずれたときに補正する。
  **基準ホモグラフィは書き換えません。**

### 画面

メイン画面 → **設備設定** → **全体微調整**

### できること

| 操作 | 内容 |
|------|------|
| X 補正 (px) | 全解像度ピクセル単位の水平移動 |
| Y 補正 (px) | 全解像度ピクセル単位の垂直移動 |
| 回転 (deg) | 微小回転（±2.0°以内） |
| 移動量 | 0.5 px / 1 px / 5 px のステップ |
| ▲ ▼ ◀ ▶ | 選んだ量だけ移動 |
| 中心 | X/Y を 0 に戻す（回転は維持） |
| 重ね表示 | プレビューの不透明度 |
| ズーム | プレビューの拡大率 |
| 補正前を表示 | 補正前後の比較 |

### 計算方法

補正は「出力側（結合画像）座標での変換」として合成されます。

```
H_effective = T_global @ H_base
```

回転を入れる場合は、指定した回転中心（既定: 結合画像の中心）を基準に回転してから平行移動します。

> **重要**: `H[0,2]` や `H[1,2]` を直接書き換える方法は、透視変換（遠近）を含む行列では
> 正しい平行移動になりません。本アプリは変換行列の合成で計算します。

### 保存と適用

- 「保存して適用」を押すまで、**検査には反映されません**（未保存の変更はドラフト扱い）。
- 保存すると `aikensa/core/param/adjustments/global_alignment.yaml` が更新されます。
- 保存のたびに版（リビジョン）が記録され、「設定履歴」から戻せます。
- 保存後、稼働中の検査スレッドにも自動で再読込されます。

### 保存される内容

```yaml
cam2:
  x_px: 0.0        # 全解像度ピクセル
  y_px: 0.0
  rotation_deg: 0.0
pivot_px: null     # null のときは結合画像の中心
limits:
  max_abs_shift_px: 500.0
  max_abs_rotation_deg: 2.0
```

## 品番別（ウィジェット別）調整

### 画面

メイン画面 → **設備設定** → **品番別設定**

### できること

- 品番（ウィジェット）を選ぶ
- カメラ②の X / Y オフセット、回転
- 切り出し範囲（X, Y, 幅, 高さ）
- カタブ切り出し範囲（任意）
- 結合画像プレビューと切り出しプレビュー
- 「共通既定値に戻す」
- 「他品番からコピー」

### 優先順位

```
共有既定値 (part_registry.yaml)
   └→ 設備固有の上書き (widget_adjustments.yaml)   ← こちらが優先
```

「共通既定値に戻す」は、設備固有の上書きを削除するだけです。共有既定値は変更しません。

### 安全装置

- ウィジェット A の変更がウィジェット B に影響することはありません
  （保存時もウィジェット ID ごとに独立して記録されます）。
- オフセットは ±300 px、回転は ±2° を超えると保存できません。
- 未保存の変更はドラフトであり、検査には反映されません。
- 保存・戻す操作は、すべて版として記録されます。

### 既存の 8 数値クロップとの互換性

従来の `widget_crop_points` は 8 数値（四角形の 4 点）で記述されています。
検査コードは実際には**外接矩形**のみを使用してきたため、本 UI では
`x, y, 幅, 高さ` で編集し、内部で 8 数値形式との相互変換を行います。

```python
# 変換の実装
crop_from_legacy_points([x1,y1, x2,y2, x3,y3, x4,y4]) -> CropRect
legacy_points_from_crop(CropRect) -> [x1,y1, x2,y2, x3,y3, x4,y4]
```

台形補正（四点透視変換）は実装されていないため、UI には表示していません。

### 保存先

`aikensa/core/param/adjustments/widget_adjustments.yaml`（Git 管理外）

```yaml
widgets:
  "43":
    part_number: P658107YA0A
    cam2_offset_x_px: 1.5
    cam2_offset_y_px: -2.5
    cam2_rotation_deg: 0.0
    crop: [10, 20, 200, 100]
    katabu_crop: null
```
