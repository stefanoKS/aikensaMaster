# 3. カメラのシリアル番号割当

## 画面の開き方

メイン画面 → **設備設定**（黄色いボタン）→ 左メニュー **カメラ設定**

## 論理カメラと物理カメラの対応

| 論理番号 | 画面表記 | 使用する校正ファイル |
|----------|----------|----------------------|
| 0 | カメラ① | `Calibration_camera_0.yaml` |
| 1 | カメラ② | `Calibration_camera_1.yaml` |

**論理番号と表示番号は一致しません**（0 起点）。校正ファイル名は 0 起点、
ホモグラフィのファイル名は `cam1` / `cam2`（1 起点）です。これは既存仕様の互換性のためです。

## 手順

1. **カメラ検索 / 更新** を押します。
   - IC4 SDK が使える環境では、接続中のカメラのシリアル番号が一覧に表示されます。
   - ライブラリが無い場合は「IC4 ライブラリが見つかりません」と表示されます。
     その場合はシリアル番号を直接入力してください（コンボボックスは編集可能です）。
2. **カメラ① / カメラ② のシリアル番号** を選択または入力します。
3. 解像度・FPS・露光時間・ゲイン・色温度・ホワイトバランス比を必要に応じて変更します。
4. **接続テスト** を押して、状態欄に「接続OK (3072x2048)」と表示されることを確認します。
   - 実測値欄にはカメラから読み戻した値が表示されます。
5. **保存** を押します。

## 入力規則（自動検証）

| 項目 | 範囲 | 違反時 |
|------|------|--------|
| シリアル番号 | 空欄不可（両カメラ） | エラー: 保存不可 |
| シリアル番号の重複 | 禁止 | エラー: 保存不可 |
| 解像度 | 幅 320〜5472 px / 高さ 240〜3648 px | エラー: 保存不可 |
| FPS | 1〜120 | エラー: 保存不可 |
| 露光時間 | 10〜5,000,000 μs | エラー: 保存不可 |
| ゲイン | 0〜48 dB | エラー: 保存不可 |
| 色温度 | 1000〜12000 K | エラー: 保存不可 |
| WB比 (R/G/B) | 0.05〜20 | エラー: 保存不可 |

画面下部にエラー内容が日本語で表示されます。**エラーがある間は保存されません。**

## 自動露出 / 自動ゲイン / 自動ホワイトバランスについて

これらの自動制御は**色安定性のため意図的に無効**です。
カメラ設定画面では「固定 (色安定のため変更不可)」と表示され、編集できません。
`cam_init_ic4.py` は起動時に強制的にマニュアルモードへ設定します。

## 保存先

`aikensa/core/config/cam/cam_id.yaml`（シリアル番号）
`aikensa/core/config/cam/cam_config.yaml`（動作パラメータ）

これらは **Git 管理外**です。`git pull` で他の設備の値に置き換わることはありません
（[git_pull_protection.md](git_pull_protection.md) 参照）。

## 注意

- シリアル番号を変更すると、そのカメラの校正は「不適合 (再校正が必要)」になります。
- 解像度や 180°回転の設定を変更した場合も同様に再校正が必要です。
- 旧形式（`0: 0` のようなカメラ番号）の設定はそのまま動作しますが、
  「旧形式のカメラ番号で設定されています」という注意が表示されます。
  シリアル番号へ移行してください。
