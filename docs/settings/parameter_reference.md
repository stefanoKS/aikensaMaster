# パラメータ一覧表

「適用タイミング」の凡例:

- **即時** … 保存直後に画面へ反映（ただし保存前の値はドラフト）
- **次回開始** … 次に検査／校正を開始したとき
- **要再起動** … アプリ再起動後に反映
- **要再校正** … 変更すると校正データが「不適合」になり再校正が必要

## 日常点検（点検位置1～3）

「設備設定」→「日常点検設定」で位置を選び、基準寸法 [mm]、許容差 [mm]、
画素換算係数 [mm/px] を変更できます。入力の検証や位置選択だけでは点検結果は
変わりません。「承認して保存」後、次回の点検から選んだ位置にだけ適用されます。
「共通値を使用」で位置別の上書きを解除できます。検出範囲・モデル・信頼度・
推論画像サイズはこの画面では参照専用です。

測定値は水平方向の長さを小数1桁に丸めた実測値です。判定が OK でも基準値で
置き換えません。日常点検の設定履歴は画面内に表示され、以前の版へ戻せます。
品番別調整やカメラ設定の履歴とは独立しています。

承認・復元には変更作業者と理由が必要です。承認した版は共通値を含めて保存され、
配備ファイルの更新だけでは変わりません。設定履歴から承認済みの版を選ぶと、
復元を新しい版として記録します。「現在配備されている共通設定」は履歴の復元とは
異なり、現在の共通設定を適用します。旧形式の履歴（位置別の変更のみ）は、
現在の共通設定を使って解決され、承認または復元時に新形式で保存されます。

## 単位について

- **px (全解像度)** … カメラのネイティブ解像度（例 3072x2048）での画素
- **px (縮小)** … プレビュー用（ネイティブの 1/5）
- 微調整はすべて**全解像度 px** で保存し、縮小プレビューへは係数で換算されます
  （整数除算で端数が出る場合も実際の画像サイズから係数を算出します）
- `pixelMultiplier` は **mm / pixel** です（1 px が何 mm か）
